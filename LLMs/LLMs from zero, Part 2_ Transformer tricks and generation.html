Module 3Transformer tricks

3.1 Giving the model a sense of order

From Part 1: attention treats the input like a bag of words. "Dog bites man" and "man bites dog" look the same. So we must inject position somehow. There are three main ways.

MethodHow it worksUsed inWeakness
Sinusoidal (fixed)Add a fixed wave pattern to each embedding. Each position gets a unique "barcode".Original 2017 TransformerDoesn't generalize well to longer texts than seen in training
Learned absoluteA learned vector for position 0, 1, 2, … up to a max (e.g., 512), added to the embeddingBERT, GPT-2Hard limit: there's no vector for position 513
RoPE (rotary)Rotate the query and key vectors by an angle that depends on positionLlama, Mistral, Qwen, GemmaNeeds tricks to stretch beyond training length (but those tricks work well)

What the sinusoidal "barcode" looks like

PE(pos, 2i) = sin(pos / 10000^(2i/d))    PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

Each dimension is a wave with a different speed. Early dimensions wiggle fast, later ones slowly. Like the hands of a clock: the seconds hand moves fast, the hour hand slowly, and together they give every moment a unique reading.

Rows = positions 0 to 49 (top to bottom). Columns = embedding dimensions 0 to 63. Blue = positive, orange = negative. Each row is different, so each position is unique.

3.2 RoPE: rotary position embeddings

RoPE is the method you must know, because almost every open model uses it. The idea: instead of adding a position vector, rotate the query and key vectors. A token at position m is rotated by angle m·θ.

Why rotate? When you take the dot product of two rotated vectors, only the difference of their angles matters. So the attention score between two tokens depends on how far apart they are (m − n), not where they sit in the text. That's exactly what we want: "the word 2 places back" should mean the same thing at the start or the end of a document.

Drag "shift both": the two arrows spin together, but the angle between them, and so the score, stays exactly the same. Change m or n and the score changes.

In a real model, the vector is split into pairs of numbers, and each pair is rotated at a different speed (like the sinusoidal waves). RoPE is applied to Q and K only, not to V, and it's applied inside every attention layer.

Interview follow-up: "How do models extend context from 4k to 128k?" Since RoPE uses angles, you can squeeze positions so that longer texts fit into the angle range seen in training. Names to drop: position interpolation, NTK-aware scaling, and YaRN, usually followed by a short fine-tune on long documents. Another option is ALiBi, which skips position vectors and just subtracts a penalty from attention scores that grows with distance.

3.3 MHA vs MQA vs GQA: saving memory at inference

When an LLM generates text, it stores the keys and values of all previous tokens so it doesn't recompute them (the KV cache, explained fully in 4.3). With many heads and long context, this cache gets huge. The fix: let several query heads share the same key and value heads.

How BERT is trained: masked language modeling (MLM)

Hide 15% of the words and ask the model to guess them using context on both sides. Toggle below to see why seeing both sides matters.

Of the chosen 15%: 80% are replaced with [MASK], 10% with a random word, and 10% left unchanged. This stops the model from only learning to handle the [MASK] symbol, which never appears in real use. Original BERT also had a second task, next sentence prediction (NSP): are these two sentences consecutive? A special [CLS] token at the start collects a summary of the whole input for classification.

BERT variantWhat changed
RoBERTaDropped NSP (it didn't help), trained longer on more data, and changed which words are masked every epoch (dynamic masking)
DistilBERTA smaller student model trained to copy BERT (knowledge distillation): about 40% smaller, 60% faster, keeps about 97% of the performance
ALBERTShares weights across layers to cut parameters
"Why did decoder-only models win?" One simple objective (next token) works on any text with no labels, it scales smoothly with more data and compute, and a single model can do any task just by being prompted. Encoders still win for cheap, fast embeddings and classification.

3.5 Making attention cheaper

Full attention is O(n²). Some designs limit which tokens each token looks at:

IdeaPlain wordsExample
Sliding windowEach token only looks at the last W tokens (e.g., 4,096). Stacking layers still lets information travel far.Mistral 7B, Longformer
Sparse / global tokensMostly local attention, plus a few special tokens that see everythingLongformer, BigBird
Linear attentionRewrites the math to avoid the n × n table, at some quality costResearch models

Don't confuse these with FlashAttention (Part 3): it computes the exact same full attention, just with smarter memory use.

Check yourself: why does RoPE make the score depend only on distance?Both vectors are rotated by their own position's angle. The dot product depends on the angle between them, which is (m − n)·θ. Shift both positions by the same amount and the angle between them doesn't change.

4.2 Temperature, top-k, top-p: play with all three

pᵢ = exp(zᵢ / T) / Σⱼ exp(zⱼ / T)

Temperature T divides the logits before softmax. Low T makes the top word dominate (confident, boring). High T flattens everything (creative, risky). T → 0 is the same as greedy.

Top-k keeps only the k most likely words. Top-p (nucleus sampling) keeps the smallest set of top words whose probabilities add up to at least p. Then the kept probabilities are rescaled to sum to 1.

Faded bars are filtered out. Try T = 2 with top-p = 1 (you'll see "banana"), then top-p = 0.8 (the nonsense disappears).

"Top-k vs top-p?" Top-k always keeps exactly k words, even when the model is very sure (then k is too many) or very unsure (then k is too few). Top-p adapts: when the model is sure, the nucleus is 1 or 2 words; when unsure, it grows. Typical chat settings: T ≈ 0.7, top-p ≈ 0.9. For code or facts, use low temperature.

4.3 The KV cache: why generation doesn't redo everything

To generate token 100, attention needs the keys and values of tokens 1 to 99. But those didn't change since the last step. So we save them and only compute K and V for the one new token.

PhaseWhat happensBottleneck
PrefillThe whole prompt is processed at once, filling the cacheCompute (lots of math in parallel). Sets the time to first token.
DecodeOne new token per step, reading the whole cache each timeMemory bandwidth (moving the cache and weights). Sets tokens per second.

The cost: memory. That's why GQA (3.3) and tricks like PagedAttention (used in vLLM, stores the cache in small pages like an operating system) matter.

4.4 Mixture of experts (MoE)

In an MoE model, the single feed-forward network in each block is replaced by many smaller ones called experts. A small router looks at each token and sends it to only the top few experts (often 2 out of 8). Click a token:

The key idea: total vs active parametersMixtral 8×7B has about 47B parameters in total, but each token only uses about 13B of them. You get the knowledge capacity of a big model at the speed of a smaller one. The catch: all 47B still have to fit in memory.

One more detail interviewers like: without care, the router sends everything to one or two favorite experts. A load-balancing loss during training pushes it to spread tokens evenly.

4.5 Context window

The context window is the maximum number of tokens (prompt + answer) the model can handle at once. It's limited by attention cost (O(n²)), KV cache memory, and what position lengths the model was trained on.

Trap: "Bigger context means the model uses all of it well." Not always. Studies found a "lost in the middle" effect: models use information at the start and end of a long prompt better than information in the middle. Put the most important instructions and facts at the start or end.

4.6 Prompting: getting better answers without training

TechniqueWhat you doExample
Zero-shotJust ask"Classify this review as positive or negative: …"
Few-shot (in-context learning)Show a few solved examples in the prompt firstThree labeled reviews, then the new one
Chain of thought (CoT)Ask the model to reason step by step before answering"Let's think step by step."
Self-consistencySample several reasoning paths (with temperature > 0) and take the most common final answerMajority vote over 5 to 40 samples
In-context learning changes no weightsThe model "learns" from examples in the prompt only for that one request. Nothing is saved. This surprised researchers when GPT-3 showed it (2020), and it's a favorite interview question.

Why does CoT help? Each generated token gets the same fixed amount of computation. Writing out steps gives the model more tokens, so more computation, and each step can build on the previous one written in the context.

Self-consistency demo

Question: Pens cost ₹12 each. Riya buys 3 and pays with ₹50. How much change does she get?

Any single sample can be wrong. The majority is usually right, because correct reasoning tends to converge on the same answer while mistakes scatter.

ReviseInterview answers

Why do we need positional encodings?Attention is permutation-invariant: it treats the input as an unordered set. Without position information, word order is invisible.
What is RoPE and why is it popular?It rotates query and key vectors by an angle proportional to position. The dot product then depends only on relative distance. It needs no extra parameters and can be stretched to longer contexts with interpolation tricks.
Explain MQA and GQA.MQA: all query heads share one K/V head. GQA: query heads are split into groups and each group shares a K/V head. Both shrink the KV cache and speed up decoding; GQA keeps quality close to full multi-head attention.
BERT vs GPT?BERT is encoder-only, bidirectional, trained with masked language modeling; great for understanding tasks and embeddings. GPT is decoder-only, causal, trained on next-token prediction; great for generation.
What does temperature do?Divides logits before softmax. Below 1 sharpens the distribution (more deterministic); above 1 flattens it (more random). T → 0 equals greedy.
Top-k vs top-p?Top-k keeps a fixed number of candidates. Top-p keeps the smallest set whose probabilities sum to p, so it adapts to how confident the model is.
What is the KV cache and what's its downside?It stores keys and values of past tokens so each new token only computes its own. It turns repeated work into memory use, and that memory grows with layers, heads, context length, and batch size.
Prefill vs decode?Prefill processes the prompt in parallel (compute-bound, sets time to first token). Decode generates one token at a time (memory-bandwidth-bound, sets tokens per second).
What is a mixture of experts?The FFN is replaced by many experts and a router that sends each token to the top-k of them. Total parameters are large but active parameters per token are small. Needs a load-balancing loss.
What is in-context learning?The model performs a new task from examples given in the prompt, with no weight updates.
Chain of thought vs self-consistency?CoT asks for step-by-step reasoning in one answer. Self-consistency samples many CoT answers and takes a majority vote on the final result.
